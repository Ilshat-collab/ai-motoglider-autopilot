# ИИ-модуль уклонения от препятствий для мотопланера (MuJoCo)

Нейросетевой модуль автономного управления мотопланером: полёт к цели, обход статических и динамических препятствий, минимизация энергии.

---

## 📂 Состав проекта

| Файл | Назначение |
| :--- | :--- |
| `motoglider.xml` | Модель MJCF: планер, рули, винт, стереопара, датчик ветра, статичные и движущиеся препятствия, маркер цели; все характеристики в разделе custom. |
| `motoglider.py` | Физика: аэродинамика (ГОСТ 20058-80), тяга, четыре канала ПИД, ветер, движение препятствий, карта глубины стереопары, столкновения. |
| `check_model.py` | Проверка модели одной командой. |
| `ai_common.py` | Модуль уклонения: восприятие по стереокамере и IMU, наблюдение сети, предохранитель (fallback), исполнитель уставок со сторожевым таймером реакции, базовый навигатор, сцены методики испытаний ТЗ. |
| `ai_pilot.py` | Сеть ActorCritic (CNN карты глубины + GRU), экспорт в ONNX и замер инференса. |
| `ai_env.py` | Среда обучения с подкреплением. |
| `ai_bc.py` | Обучение подражанием базовому навигатору (старт для PPO). |
| `ai_train.py` | PPO с рекуррентной сетью. |
| `ai_eval.py` | Испытания, протокол и вердикт по параметрам ТЗ. |
| `fly_demo.py` | Полёт в окне MuJoCo с вводом цели и командами оператора. |

## Как устроен модуль

### Восприятие (ai_common.Perception)
Работает только от бортовых датчиков: карта глубины левой камеры стереопары переводится в облако точек по ориентации IMU, земля отсекается по высоте точки. Препятствие ищется в коридоре шириной 24 м вдоль прогнозируемой траектории (дуга разворота по текущему крену), подтверждается не менее чем 3 точками (порог чувствительности против ложных срабатываний). Точки препятствий помнятся 5 с: препятствие, ушедшее из кадра вбок, остается известным. При потере изображения (засветка) карта глубины до 1 с прогнозируется по IMU из последнего кадра; дольше модуль считается слепым и выполняет набор высоты.

### Сеть
Получает 26 навигационных признаков (скорость, углы, ориентация, угловые скорости, ветер от анемометра, направление, дальность и угол места цели, высота, заряд, текущие уставки) и обратную карту глубины 40x64; выдает уставки крена, скорости, скольжения, газа и при необходимости прямой руль высоты (экстренный режим).

### Исполнитель (ai_common.Executor)
Ограничивает уставку крена 27 град (запас на заброс до 30 по ТЗ) и скорость ее изменения 40 град/с (плавность; при экстренном уходе 90 град/с). 

Сторожевой таймер: если после обнаружения препятствия сеть за 0,2 с не начала маневр, маневр начинает предохранитель, поэтому время реакции не превышает 0,3 с.

### Предохранитель (`ai_common.Fallback`), вне сети:

*   **уход** — до столкновения меньше 2,5 с: крен 25 град в сторону без близких препятствий, полный газ, для невысокого препятствия импульс руля высоты на кабрирование;
*   **облет** — сеть не среагировала вовремя, сбоку есть просвет;
*   **набор** — облет невозможен (просвета нет), сеть не уверена, модуль слеп или высота меньше 15 м;
*   **возврат** — облет невозможен, а вершину не набрать до препятствия или она не видна.

Пролет над препятствием допускается только в режиме предохранителя: сеть за него штрафуется.

## Поведение в полете

Пилот держит высоту цели, подходит к ней плавно и обходит препятствия сбоку. Пролет над препятствием, которое поднимается в эшелон цели, сети запрещен штрафом.

## Награда при обучении (`ai_env.py`)

Значения взяты из исходного `ai_env.py` (в тексте ТЗ таблицы наград нет) и не менялись:

*   приближение: +0.01/м
*   цель: +10
*   авария: -10
*   энергия: -0.05/кДж
*   включение мотора: -0.2
*   высота < 30 м: -0.2/с
*   препятствие < 15 м: -0.5/с
*   резкость уставок: -0.02
*   время: -0.01/с
*   экстренный режим и работа предохранителя: -0.1/с.

**Добавлено:** отклонение от высоты цели до -0.05/с, пролет сети над препятствием -0.5/с, временный бонус за экстренный режим у препятствия (ключ `--em-bonus`, по умолчанию 0).

## Сценарии и синтетический датасет

Данные генерируются в симуляторе, файлов датасета нет. Эпизод обучения:

*   **Сцена методики ТЗ (50 % эпизодов):** одно препятствие на маршруте на высоте цели, тип случайно из пяти: дерево (эллипсоид, полуоси 19-22 и 29-34 м), группа деревьев (дерево и два ствола-цилиндра рядом), здание (параллелепипед, полуразмеры 45-54 x 30-36 x 37-45 м), ЛЭП (три опоры поперек маршрута через 45-60 м), скала (шар радиусом 40-46 м, наполовину в земле); смещение поперек маршрута до 8 м, курс случайный;
*   **Иначе случайная сцена симулятора:** препятствия случайного размера в коридоре 200 м вдоль маршрута 0,8-2,5 км, движущиеся аэростаты и дирижабль;
*   **Общие параметры:** высота цели 40-120 м, старт около нее, скорость 10-16 м/с, ветер 0-8 м/с с любого направления, внезапное препятствие (шар 6 м) в 25-50 м с вероятностью 0,3, потеря изображения на 0,2-1 с с вероятностью 0,2.

## Испытания (`ai_eval.py`)

*   **`tz20`** — методика ТЗ: полет на 50 м со скоростью 15 м/с, 20 прогонов, по 4 на каждый тип препятствия в случайном порядке, ветер 0-8 м/с; по ним выносится вердикт по пяти параметрам таблицы ТЗ (доля без столкновений, время реакции, зазор, частота обработки кадров, крен);
*   **`default`**, **`wind8`** (ветер 8 м/с), **`sudden`** (внезапный шар в 25 м), **`blackout`** (потеря изображения на 1 с сразу после обнаружения препятствия), **`random`** (случайные сцены).

Зазор считается от законцовки крыла (расстояние от центра минус полуразмах 1,98 м). Время реакции: от обнаружения препятствия модулем (дальность по траектории меньше 150 м) до первой команды маневра, плюс время обработки кадра. Время обработки кадра: восприятие и решение сети без отрисовки сцены симулятором.

С ключом `--log` папка получает `protocol.csv` (строка на прогон) и `traj_*.csv` (траектории с отметками угрозы, предохранителя, экстренного режима и потери кадра).

## Демонстрация

```bash
python fly_demo.py
python fly_demo.py --tz-scene здание --wind 6 90
python fly_demo.py --wind 5 270 --random-obstacles

Модуль включается автоматически при старте. 
```
**Консоль:**
*   `X Y Z` и `Enter` — новая цель
*   `s` — внезапное препятствие в 80 м
*   `m` — ручной режим (автоматическое уклонение выключено, повтор включает)
*   `b` — потеря изображения на 1 с
*   `q` — выход

При обнаружении препятствия звуковой сигнал и сообщение; след траектории красный во время уклонения предохранителем и в экстренном режиме. Цель в окне: двойной щелчок по красной сфере, затем правая кнопка с нажатым `Ctrl`. На macOS через `mjpython`.

## Ограничения

Шаг симулятора 0,1 с задан в `motoglider.py`, поэтому в замкнутом контуре модуль получает 10 кадров/с; частота 20 кадров/с из ТЗ проверяется по времени обработки кадра (`ai_eval.py`, `ai_pilot.py`). 

В `motoglider.xml` нет проводов: ЛЭП представлена опорами.

## Как пользоваться моделью в своем коде

```python
import motoglider as mg

sim = mg.GliderSim(depth=True)
s = sim.reset(wind=(5, 270))            # ветер 5 м/с, дует с запада

s = sim.step(gamma, V, beta, throttle)   # крен, скольжение в радианах; скорость м/с; газ 0...1; шаг 0,1 с

s = sim.step(gamma, V, beta, throttle, elevator=0.2)   # экстренный режим: руль высоты напрямую, рад

start, goal, heading = sim.randomize_scene()   # случайная сцена, затем sim.reset(start=..., goal=..., heading_deg=...)

sim.spawn_obstacle(50)   # внезапное препятствие в 50 м по курсу

sim.depth(), sim.rays(), sim.obstacles(), sim.wind(), s["crashed"], s["reason"]
```
## Важно

Если открыть `motoglider.xml` в обычном `simulate`, сцена видна, но планер падает: подъемную силу MuJoCo не считает, она прикладывается из `motoglider.py`.

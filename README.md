# ИИ-модуль уклонения от препятствий для мотопланера (MuJoCo)

Нейросетевой модуль автономного управления мотопланером: полёт к цели, обход статических и динамических препятствий, минимизация энергии.

---

## 📂 Состав проекта

| Файл | Назначение |
| :--- | :--- |
| `motoglider.xml` | Модель MJCF: планер, рули, винт, стереопара, датчик ветра, статичные и движущиеся препятствия, маркер цели; все характеристики в разделе custom. |
| `motoglider.py` | Физика: аэродинамика (ГОСТ 20058-80), тяга, четыре канала ПИД, ветер, движение препятствий, карта глубины стереопары, столкновения. |
| `check_model.py` | Проверка модели одной командой. |
| `ai_common.py` | Модуль уклонения: восприятие по стереокамере и IMU, наблюдение сети, предохранитель (fallback), исполнитель уставок со сторожевым таймером реакции, базовый навигатор, сцены методики испытаний ТЗ. |
| `ai_pilot.py` | Сеть ActorCritic (CNN карты глубины + GRU), экспорт в ONNX и замер инференса. |
| `ai_env.py` | Среда обучения с подкреплением. |
| `ai_bc.py` | Обучение подражанием базовому навигатору (старт для PPO). |
| `ai_train.py` | PPO с рекуррентной сетью. |
| `ai_eval.py` | Испытания, протокол и вердикт по параметрам ТЗ. |
| `fly_demo.py` | Полёт в окне MuJoCo с вводом цели и командами оператора. |

## Порядок работы

```bash
python check_model.py                                   # проверка модели, код возврата 0
python ai_eval.py --baseline --only tz20                # испытание базового навигатора с модулем
python ai_bc.py --out ai_pilot_bc.pth                   # обучение подражанием
python ai_train.py --updates 200 --em-bonus 0.05        # PPO, веса в ai_pilot.pth
python ai_eval.py --model ai_pilot.pth --log protocol   # испытания сети, протокол и траектории
python ai_pilot.py --weights ai_pilot.pth --onnx ai_pilot.onnx   # модель .onnx, размер, время инференса
```

## Как устроен модуль

### Восприятие (ai_common.Perception)
Работает только от бортовых датчиков: карта глубины левой камеры стереопары переводится в облако точек по ориентации IMU, земля отсекается по высоте точки. Препятствие ищется в коридоре шириной 24 м вдоль прогнозируемой траектории (дуга разворота по текущему крену), подтверждается не менее чем 3 точками (порог чувствительности против ложных срабатываний). Точки препятствий помнятся 5 с: препятствие, ушедшее из кадра вбок, остается известным. При потере изображения (засветка) карта глубины до 1 с прогнозируется по IMU из последнего кадра; дольше модуль считается слепым и выполняет набор высоты.

### Сеть
Получает 26 навигационных признаков (скорость, углы, ориентация, угловые скорости, ветер от анемометра, направление, дальность и угол места цели, высота, заряд, текущие уставки) и обратную карту глубины 40x64; выдает уставки крена, скорости, скольжения, газа и при необходимости прямой руль высоты (экстренный режим).

### Исполнитель (ai_common.Executor)
Ограничивает уставку крена 27 град (запас на заброс до 30 по ТЗ) и скорость ее изменения 40 град/с (плавность; при экстренном уходе 90 град/с). 

Сторожевой таймер: если после обнаружения препятствия сеть за 0,2 с не начала маневр, маневр начинает предохранитель, поэтому время реакции не превышает 0,3 с.

### Предохранитель (`ai_common.Fallback`), вне сети:

*   **уход** — до столкновения меньше 2,5 с: крен 25 град в сторону без близких препятствий, полный газ, для невысокого препятствия импульс руля высоты на кабрирование;
*   **облет** — сеть не среагировала вовремя, сбоку есть просвет;
*   **набор** — облет невозможен (просвета нет), сеть не уверена, модуль слеп или высота меньше 15 м;
*   **возврат** — облет невозможен, а вершину не набрать до препятствия или она не видна.

Пролет над препятствием допускается только в режиме предохранителя: сеть за него штрафуется.

## Поведение в полете

Пилот держит высоту цели, подходит к ней плавно и обходит препятствия сбоку. Пролет над препятствием, которое поднимается в эшелон цели, сети запрещен штрафом.

## Награда при обучении (`ai_env.py`)

Значения взяты из исходного `ai_env.py` (в тексте ТЗ таблицы наград нет) и не менялись:

*   приближение: +0.01/м
*   цель: +10
*   авария: -10
*   энергия: -0.05/кДж
*   включение мотора: -0.2
*   высота < 30 м: -0.2/с
*   препятствие < 15 м: -0.5/с
*   резкость уставок: -0.02
*   время: -0.01/с
*   экстренный режим и работа предохранителя: -0.1/с.

**Добавлено:** отклонение от высоты цели до -0.05/с, пролет сети над препятствием -0.5/с, временный бонус за экстренный режим у препятствия (ключ `--em-bonus`, по умолчанию 0).
